# Funtopia - Cosmic Retro Event Leaderboard

A Cosmic Retro Event Leaderboard Website built with React, Vite, and Tailwind CSS.

## 🚀 Project Overview

Funtopia is an interactive cosmic retro-themed leaderboard platform designed for tracking event participants, scores, and real-time rankings with an immersive arcade / synthwave aesthetic.

## 📁 Project Structure

```text
funtopia/
├── public/              # Static assets
├── src/
│   ├── assets/          # Images, icons, audio, and font files
│   ├── components/      # Reusable UI components
│   ├── pages/           # Page-level views and routes
│   ├── services/        # API calls, event streaming, and data services
│   ├── utilities/       # Helper functions and formatting utilities
│   ├── App.jsx          # Root application component
│   ├── index.css        # Tailwind & global stylesheet
│   └── main.jsx         # Application entry point
├── .env.example         # Template for environment variables (no secrets)
├── .gitignore           # Git ignore rules for Node & environment files
├── index.html           # HTML entry point
├── package.json         # Project metadata and dependencies
├── postcss.config.js    # PostCSS configuration for Tailwind CSS
├── tailwind.config.js   # Tailwind CSS configuration
└── vite.config.js       # Vite configuration
```

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**

## 💻 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
